# KERAS 2 IS REQUIRED. 
# ===========================================================================
#
# The autoencoder applies an L1 activity regularizer to its latent layer.
# Under Keras 3 that penalty drives the latent to zero: the model degenerates
# to predicting the per-feature mean, validation loss plateaus near 0.95
# instead of 0.066, and no fault is detected.
#
# The failure is SILENT. A collapsed autoencoder still reports a ~2% healthy
# false-alarm rate, because a constant predictor trivially satisfies its own
# percentile. Only the detection rates reveal it, by falling to the false-alarm
# rate.
#
# TensorFlow 2.16 and later default to Keras 3, so on any modern TensorFlow
# you must install tf-keras and set the environment variable:
#
#     pip install -r requirements.txt
#     export TF_USE_LEGACY_KERAS=1
#
# Confirm before running anything:
#
#     python verification/check_environment.py
#
